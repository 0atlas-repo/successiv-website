# Designer hire brief — Successiv marketing site

**Status:** Draft after design-reference pass.  
**Company:** Successiv (product brand of 0atlas) — https://successiv.com (upcoming)  
**Repo:** https://github.com/0atlas-repo/successiv-website  

---

## Role

**Product / marketing designer** (contract, 2–4 weeks, remote OK; Asia timezone overlap preferred).

Design the Successiv marketing site visual system and key page layouts. Engineering implements in Next.js (Claude Code / internal). You are not hired to code the full site unless scoped separately.

---

## Goals

1. A **product-led** homepage that features four own products: Creator Sphere, Shopmgr, KYC, Leave.
2. Visual system inspired by (not copying) **Attio** (product storytelling), **Scale** (enterprise gravity), **Pryzm** (craft).
3. Anonymized Work case studies with **mocked UI** — no real clients, no real screenshots.
4. Hand-off ready for eng: Figma (or equivalent) + tokens + component notes.

| # | Deliverable |
|---|-------------|
| 1 | Moodboard + direction (1–2 options) mapped to the three refs |
| 2 | Design tokens: type, color, spacing, radius, motion notes |
| 3 | High-fi: Home, Products index, 1 product detail, Work, Contact |
| 4 | Component library: nav, product card, work card, mocked UI kit (chat, form steps, calendar, table) |
| 5 | Mobile variants for Home + Product |
| 6 | Export / redlines eng can implement without guessing |

---

## Constraints

- No real client names (esp. transit / exchange / utilities brands from internal history)
- No real product screenshots from client work — **mock only**
- Prefer light, sharp SaaS UI with one craft moment (hero/background), not full dark enterprise clone
- Accessibility: contrast AA, focus states, readable body ≥16px

---

## Nice to have

- Simple motion spec (hero, card hover, section reveal)
- Open Graph / social share image
- Optional Pricing page shell if products go commercial later

---

## Success looks like

A visitor understands in 10 seconds: **Successiv ships AI products** (not “another agency”), can name at least two products, and knows how to talk to us — while the site feels as intentional as Attio/Pryzm without pretending to be Scale-scale.
